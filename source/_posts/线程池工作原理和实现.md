线程池是一种用于优化多线程[[多线程和线程同步-C-C]]应用程序性能和资源管理的技术。其基本原理是通过预先创建一定数量的线程并将这些线程复用来执行多个任务，从而避免频繁创建和销毁线程的开销。线程池的使用可以提高应用程序的响应速度和效率，尤其是在需要处理大量短时间任务的场景中。

### 线程池的基本组成

1. **线程队列**：线程池维护一个线程队列，其中存储了一组可以复用的工作线程。这些线程在启动时创建，并在整个应用程序生命周期中保持运行状态。
    
2. **任务队列**：任务队列用于存储待执行的任务。当有新的任务提交给线程池时，任务会被添加到任务队列中。
    
3. **工作线程**：工作线程是实际执行任务的线程。在空闲状态时，工作线程会等待任务队列中有新的任务到来。一旦有任务可用，工作线程会取出任务并执行。
    
4. **任务调度器**：任务调度器负责管理任务的提交和分配。它决定何时将任务从任务队列中取出，并将其分配给空闲的工作线程。
    

### 线程池的工作原理

1. **初始化**：在线程池初始化阶段，创建一组预定义数量的工作线程，并准备好任务队列。工作线程会进入等待状态，等待任务到来。
    
2. **提交任务**：当有新的任务需要执行时，任务会被提交到线程池。任务可以是一个函数、一个方法调用或其他可执行的代码片段。
    
3. **任务分配**：任务调度器将新提交的任务放入任务队列中。如果有空闲的工作线程，则立即将任务分配给该线程执行。如果没有空闲线程，任务将继续留在队列中，等待线程变得可用。
    
4. **任务执行**：工作线程从任务队列中取出任务并执行。当任务执行完毕后，线程不会终止，而是返回等待状态，准备执行下一个任务。
    
5. **线程回收和复用**：线程池通过保持工作线程的存活来避免频繁创建和销毁线程的开销。当有新任务提交时，线程池复用现有的空闲线程来执行任务。这种复用机制大大提高了任务处理的效率。
    
6. **关闭线程池**：当应用程序结束或需要关闭线程池时，线程池会停止接收新任务，并等待所有已提交任务完成后，再终止所有工作线程。
    

### 线程池的优点

1. **性能提升**：通过复用现有线程，减少了创建和销毁线程的开销，提高了应用程序的整体性能。
    
2. **资源管理**：线程池可以限制同时运行的线程数量，从而有效控制系统资源的使用，防止资源过度占用和耗尽。
    
3. **响应速度**：预创建的线程可以快速响应任务请求，降低了任务启动的延迟。
    
4. **简化编程模型**：线程池提供了一个简单的接口用于任务提交和管理，使得开发者可以专注于任务逻辑，而不必关注线程管理的复杂性。
    

### 实现线程池的关键技术

1. **互斥锁和条件变量**：为了保证任务队列在多线程环境下的安全性，线程池通常使用互斥锁（`mutex`）和条件变量（`condition variable`）来同步线程对任务队列的访问。
    
2. **任务队列**：使用线程安全的数据结构（如队列）来存储待执行的任务。
    
3. **工作线程管理**：动态管理工作线程的数量，根据系统负载情况增加或减少工作线程。

`threadpool.c`
```cpp
/********************************************************************************
 * @author: Alan Chen
 * @email: salianbooth@gmail.com
 * @date: 2024/9/1 10:57
 * @version: 1.0
 * @description:
 ********************************************************************************/
#include "../include/threadpool.h"
#include "malloc.h"
#include "string.h"
#include "stdio.h"
#include "pthread.h"

int NUMBER = 2;

// 务结构体
typedef struct Task
{
    void (*function)(void *arg);
    void *arg;
} Task;

// 线程池结构体
struct ThreadPool
{

    // 任务队列
    Task *taskQ;
    int taskCapacity; // 容量
    int taskSize;     // 当前任务个数
    int taskFront;    // 队头->取数据
    int taskRear;     // 队尾-放数据

    pthread_t managerID;      // 管理者线程ID
    pthread_t *threadIDs;     // 工作线程ID
    int minNum;               // 最小线程数
    int maxNum;               // 最大
    int busyNum;              // busy
    int liveNum;              // 存活
    int exitNum;              // 销毁
    pthread_mutex_t lockPool; // 锁住整个线程池
    pthread_mutex_t lockBusy; // 锁住busy变量->因为整个会一直变来变去
    pthread_cond_t notFull;
    pthread_cond_t notEmpty;

    int shutdown; // 是不是销毁线程池
};

// 创建线程池
///
/// \param min -> 最少线程的数量
/// \param max -> 最多线程的数量
/// \param queueSize -> 任务队列的大小
/// \return
ThreadPool *threadPoolCreate(int min, int max, int queueSize)
{

    // 使用malloc函数进行分配
    ThreadPool *pool = (ThreadPool *)malloc(sizeof(ThreadPool));
    do
    {
        // 当线程池为NULL的时候，表明创建失败
        if (pool == NULL)
        {
            printf("malloc threadpool fail...\n");
            break;
        }
        // 这里给工作的线程分配内存 ，注意要 *max
        pool->threadIDs = (pthread_t *)malloc(sizeof(pthread_t) * max);
        if (pool->threadIDs == NULL)
        {
            printf("malloc threadIDs fail...\n");
            break;
        }

        // 先将工作的线程都初始化为1
        memset(pool->threadIDs, 0, sizeof(pthread_t) * max);
        pool->minNum = min;
        pool->maxNum = max;
        pool->busyNum = 0;
        pool->liveNum = min; // 和最小个数相等
        pool->exitNum = 0;

        // 这里是为了初始化 互斥锁 和 条件变量
        if (pthread_mutex_init(&pool->lockPool, NULL) != 0 ||
            pthread_mutex_init(&pool->lockBusy, NULL) ||
            pthread_cond_init(&pool->notEmpty, NULL) != 0 ||
            pthread_cond_init(&pool->notFull, NULL) != 0)
        {
            printf("mutex or condition init fail...\n");
            break;
        }

        // 任务队列 -> 就是相当于一个队列了
        pool->taskQ = (Task *)malloc(sizeof(Task) * queueSize);
        pool->taskCapacity = queueSize;
        pool->taskSize = 0;
        pool->taskFront = 0;
        pool->taskRear = 0;

        pool->shutdown = 0;

        // 创建线程
        // 管理者线程
        pthread_create(&pool->managerID, NULL, manager, pool);
        // 工作线程
        for (int i = 0; i < min; ++i)
        {
            pthread_create(&pool->threadIDs[i], NULL, worker, pool);
        }
        return pool;
    } while (0);

    // 释放资源
    if (pool && pool->threadIDs)
        free(pool->threadIDs);
    if (pool && pool->taskQ)
        free(pool->taskQ);
    if (pool)
        free(pool);

    return NULL;
}

// 摧毁线程池
int threadPoolDestroy(ThreadPool *pool)
{
    if (pool == NULL)
    {
        return -1;
    }

    // 关闭线程池
    pool->shutdown = 1;
    // 阻塞回收管理者线程
    pthread_join(pool->managerID, NULL);
    // 唤醒阻塞的消费者线程
    for (int i = 0; i < pool->liveNum; ++i)
    {
        pthread_cond_signal(&pool->notEmpty);
    }
    // 释放堆内存
    if (pool->taskQ)
    {
        free(pool->taskQ);
    }
    if (pool->threadIDs)
    {
        free(pool->threadIDs);
    }

    pthread_mutex_destroy(&pool->lockPool);
    pthread_mutex_destroy(&pool->lockBusy);
    pthread_cond_destroy(&pool->notEmpty);
    pthread_cond_destroy(&pool->notFull);

    free(pool);
    pool = NULL;

    return 0;
}

void threadPoolAdd(ThreadPool *pool, void (*func)(void *), void *arg)
{
    pthread_mutex_lock(&pool->lockPool);
    while (pool->taskSize == pool->taskCapacity && !pool->shutdown)
    {
        // 阻塞生产者线程
        pthread_cond_wait(&pool->notFull, &pool->lockPool);
    }
    if (pool->shutdown)
    {
        pthread_mutex_unlock(&pool->lockPool);
        return;
    }
    // 添加任务
    pool->taskQ[pool->taskRear].function = func;
    pool->taskQ[pool->taskRear].arg = arg;
    pool->taskRear = (pool->taskRear + 1) % pool->taskCapacity;
    pool->taskSize++;

    pthread_cond_signal(&pool->notEmpty);
    pthread_mutex_unlock(&pool->lockPool);
}

int threadPoolBusyNum(ThreadPool *pool)
{
    pthread_mutex_lock(&pool->lockBusy);
    int busyNum = pool->busyNum;
    pthread_mutex_unlock(&pool->lockBusy);
    return busyNum;
}

int threadPoolAliveNum(ThreadPool *pool)
{
    pthread_mutex_lock(&pool->lockPool);
    int aliveNum = pool->liveNum;
    pthread_mutex_unlock(&pool->lockPool);
    return aliveNum;
}

// 工作函数  void* arg -> threadpool的地址
void *worker(void *arg)
{
    ThreadPool *pool = (ThreadPool *)arg;

    while (1)
    {
        pthread_mutex_lock(&pool->lockPool);
        // 当前任务队列是否为空 -> 为空 - 说明现在没有任务可以做 ，那么就需要阻塞工作现场
        while (pool->taskSize == 0 && !pool->shutdown)
        {
            // 阻塞工作线程
            pthread_cond_wait(&pool->notEmpty, &pool->lockPool);

            // 判断是不是要销毁线程
            if (pool->exitNum > 0)
            {
                pool->exitNum--;
                // 这里要继续判断存活的线程是否小于最小线程个数
                if (pool->liveNum > pool->minNum)
                {
                    pool->liveNum--;
                    pthread_mutex_unlock(&pool->lockPool);
                    threadExit(pool);
                }
            }
        }

        // 判断线程池是否被关闭了
        if (pool->shutdown)
        {
            pthread_mutex_unlock(&pool->lockPool);
            threadExit(pool);
        }

        // 从任务队列中取出一个任务
        Task task;
        task.function = pool->taskQ[pool->taskFront].function;
        task.arg = pool->taskQ[pool->taskFront].arg;
        // 移动头结点 -> 这里是循环队列
        pool->taskFront = (pool->taskFront + 1) % pool->taskCapacity;
        pool->taskSize--; // 取出了1个任务，那么任务的个数要--
        // 解锁
        pthread_cond_signal(&pool->notFull);
        pthread_mutex_unlock(&pool->lockPool);

        printf("thread %ld start working...\n", pthread_self());
        pthread_mutex_lock(&pool->lockBusy);
        pool->busyNum++; // 因为取出了1个任务，这个时候就会有线程进行工作
        pthread_mutex_unlock(&pool->lockBusy);
        task.function(task.arg);
        free(task.arg);
        task.arg = NULL;

        printf("thread %ld end working...\n", pthread_self());
        pthread_mutex_lock(&pool->lockBusy);
        pool->busyNum--;
        pthread_mutex_unlock(&pool->lockBusy);
    }
    return NULL;
}

// 管理者函数
void *manager(void *arg)
{
    ThreadPool *pool = (ThreadPool *)arg;
    // 只要不销毁线程池，管理者函数就会每3s执行检查
    while (!pool->shutdown)
    {
        // 每隔3s检测一次
        sleep(3);

        // 取出线程池中任务的数量和当前线程的数量
        pthread_mutex_lock(&pool->lockPool);
        int queueSize = pool->taskSize;
        int liveNum = pool->liveNum;
        pthread_mutex_unlock(&pool->lockPool);

        // 取出忙的线程的数量
        pthread_mutex_lock(&pool->lockBusy);
        int busyNum = pool->busyNum;
        pthread_mutex_unlock(&pool->lockBusy);

        // 添加线程
        // 任务的个数>存活的线程个数 && 存活的线程数<最大线程数
        if (queueSize > liveNum && liveNum < pool->maxNum)
        {
            pthread_mutex_lock(&pool->lockPool);
            int counter = 0;
            for (int i = 0; i < pool->maxNum && counter < NUMBER && pool->liveNum < pool->maxNum; ++i)
            {
                if (pool->threadIDs[i] == 0)
                {
                    // 这里就是要创建的线程，最后传入的参数就是给worker函数的参数
                    pthread_create(&pool->threadIDs[i], NULL, worker, pool);
                    counter++;
                    pool->liveNum++;
                }
            }
            pthread_mutex_unlock(&pool->lockPool);
        }
        // 销毁线程
        // 忙的线程*2 < 存活的线程数 && 存活的线程>最小线程数
        if (busyNum * 2 < liveNum && liveNum > pool->minNum)
        {
            pthread_mutex_lock(&pool->lockPool);
            pool->exitNum = NUMBER;
            pthread_mutex_unlock(&pool->lockPool);
            // 让工作的线程自杀
            for (int i = 0; i < NUMBER; ++i)
            {
                pthread_cond_signal(&pool->notEmpty);
            }
        }
    }
    return NULL;
}

void threadExit(ThreadPool *pool)
{
    pthread_t tid = pthread_self();
    for (int i = 0; i < pool->maxNum; ++i)
    {
        if (pool->threadIDs[i] == tid)
        {
            pool->threadIDs[i] = 0;
            printf("threadExit() called, %ld exiting...\n", tid);
            break;
        }
    }
    pthread_exit(NULL);
}

void taskFunc(void *arg)
{
    int num = *(int *)arg;
    printf("thread %ld is working, number = %d\n",
           pthread_self(), num);
    sleep(1);
}

int main()
{
    // 创建线程池
    ThreadPool *pool = threadPoolCreate(3, 10, 100);
    for (int i = 0; i < 100; ++i)
    {
        int *num = (int *)malloc(sizeof(int));
        *num = i + 100;
        threadPoolAdd(pool, taskFunc, num);
    }

    sleep(30);

    threadPoolDestroy(pool);
    return 0;
}
```
